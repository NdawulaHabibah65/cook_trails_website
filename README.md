# Cook Trails Website

A simple first-launch landing page for the Cook Trails Android app.

## Preview locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Add the APK

After building the Flutter release APK, copy it into:

`downloads/cook-trails.apk`

The website's Download APK button is already configured to download that file.

## Main files

- `index.html` — website content
- `css/style.css` — design and responsive layout
- `downloads/cook-trails.apk` — add the release APK here
